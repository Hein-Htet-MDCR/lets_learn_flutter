### Week 1: Introduction to Dart & Environment Setup

#### Learning Outcomes
By the end of this week, students will be able to:
* **Understand** what Flutter is and why it is popular.
* **Explain** the difference between cross-platform and native development.
* **Install** Flutter development tools.
* **Create and run** a Flutter project.
* **Understand** basic Dart programming concepts.
* **Create** simple classes and work with collections.

---

### Week 2: Flutter UI Fundamentals (The Widget Tree)

#### Learning Outcomes
By the end of this week, students will be able to:
* **Understand** the Widget Tree concept.
* **Create** application structure using `MaterialApp` and `Scaffold`.
* **Display** text and icons.
* **Build** layouts using `Row`, `Column`, and `Container`.
* **Handle** user interaction with buttons and gestures.
* **Capture** user input using `TextField`.
* **Display** scrollable lists and grid layouts.
